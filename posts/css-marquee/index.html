When using Tailwind v4, if you want the styles pre-generated so you can just write animate-marquee as a class, we need to include the keyframe within the @theme config.

input file

site2.css:

@theme {
  --animate-marquee1: marquee1 15s linear infinite;
  --animate-marquee2: marquee2 15s linear infinite;
  
  @keyframes marquee1 {
        0% {
          transform: translateX(0%);
        }
        100% {
          transform: translateX(-100%);
        }
    }
    @keyframes marquee2 {
        0% {
          transform: translateX(100%);
        }
        100% {
          transform: translateX(0%);
        }
    }

}

output

npx @tailwindcss/cli -i ./wwwroot/css/site2.css -o ./wwwroot/css/site2tw.css --optimize
